# U9: čistá komunikácia vozidlo ↔ vozidlo

Režim `v2v_only` je vetvou toho istého CLI a editora U9. Vyžaduje aspoň dve autá s ITS-G5, prázdny zoznam RSU, `rsu_id: ""`, `satellite: null` a `direct_cars: []`. Všetky autá v dopyte vysielajú CAM podľa svojho SUMO pohybu; ns-3.38 OCB rádio a Vanetza vytvoria skutočné rámce. Checker porovná generované CAM/GN bajty s PCAP každého uzla, prijímateľov, časovanie, FCD, DCC a PHY stopy. Výsledok nemá satelitný tok ani infraštruktúrnu odpoveď.

```bash
.venv/bin/python tools/bp_u9.py preflight config/u9-v2v-24cars-no-rsu.json
.venv/bin/python tools/bp_u9.py run config/u9-v2v-24cars-no-rsu.json results/u9_runs/MOJE_NOVE_ID
.venv/bin/python tools/bp_u9.py verify results/u9_runs/MOJE_NOVE_ID
```
