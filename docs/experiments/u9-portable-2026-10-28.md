## Obnova na inom zariadení

Podporované prostredie je Ubuntu 24.04 x86_64 a Python 3.12. Zdrojový kód ns-3.38/SNS-3 a Vanetza sú pribalené; `setup.sh` doinštaluje chýbajúce balíky Ubuntu cez `apt`, vytvorí nové `.venv` z pribalených wheels, zostaví C++ knižnice v pracovnom priečinku a spustí preflight i celý `combined_advanced` smoke beh. Nie je to potvrdená obnova na Windows, macOS ani inom Ubuntu. Priemyselné operátorské parametre zostávajú výskumnými predpokladmi.

```bash
sha256sum -c BP-Simulator.zip.sha256
unzip BP-Simulator.zip
bash BP-Simulator/setup.sh
bash BP-Simulator/run.sh preflight
bash BP-Simulator/run.sh run config/u9-advanced-24cars-31rsu-4sat.json moje-id
bash BP-Simulator/run.sh verify moje-id
bash BP-Simulator/run.sh server 8765
```

Predvolený pracovný priečinok je cez `xdg-user-dir DESKTOP` na ploche; `BP_SIM_WORKSPACE` ho môže zmeniť. `setup.sh` neprepisuje hotový runtime ani existujúce ID výsledku. JSON world/demand importuj príkazom `bash BP-Simulator/import.sh /cesta/subor.json`; súbor sa kopíruje do `runtime/data/inputs/user/` a môže byť referencovaný v scenári. CSV/OSM/XML sa uloží do `imports/`, ale pred simuláciou sa musí previesť do podporovanej U9 schémy. Obyčajné CSV súradníc zatiaľ nie je priamym vstupom modelu.
