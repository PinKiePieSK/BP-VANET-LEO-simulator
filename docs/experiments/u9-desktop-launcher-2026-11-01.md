# U9 · ikona a životný cyklus lokálneho servera

Používateľská ikona `~/Desktop/BP-Simulator.desktop` je vytvorená z prenosného balíka pomocou `install_shortcut.py`; spúšťa `launch.py` z rozbaleného `BP-Simulator`. Kód v zdrojovom projekte je v `scripts/portable_launch.py`, `scripts/portable_install_shortcut.py` a `scripts/bp-simulator.svg`. Balicí skript ich zachováva pri ďalšom vydaní. `setup.sh` vytvorí ikonu po úspešnej príprave aj pri opakovanom spustení už pripraveného balíka.

Launcher používa port 8766, ak je voľný; inak nechá systém prideliť voľný lokálny port. Server počúva iba na `127.0.0.1`. Pred otvorením prehliadača sa overí HTTP 200. Samostatný profil Firefoxu zabraňuje pripojeniu nového okna k už bežiacemu procesu. Launcher drží zámok proti duplicitnému spusteniu, po skončení prehliadača ukončí iba server, ktorý sám spustil, a odstráni dočasný profil. Denník píše do pracovného `BP-Simulator-Workspace/logs/`.

Overenie na Ubuntu 24.04: `python3 -m py_compile` pre launcher, inštalátor a server; `setup.sh` na pripravenom pracovnom runtime vrátil PASS a vytvoril vykonateľnú dôveryhodnú `.desktop` ikonu. Skúšobný prehliadač otvoril port 8766 a po skončení port neodpovedal. Pri umelo obsadenom porte 8766 launcher zvolil iný port, ponechal pôvodného poslucháča a vlastný server po skončení zavrel. Skutočný Firefox sa spustil ako samostatný proces s vlastným profilom, načítal HTML a JS cez HTTP 200; po ukončení jeho procesu launcher zavrel svoj server. `PYTHONPATH=tools .venv/bin/python -m unittest test_u9_active_server -v` prešlo. Čistý balík: `verify.py` PASS pre 11 456 súborov a odkazov, `unzip -tq` PASS, súbor `BP-Simulator.zip.sha256` PASS.
